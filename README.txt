Run locally:
1. Easiest: double-click index.html.
2. Better: open this folder in VS Code, install the "Live Server" extension, right-click index.html > Open with Live Server.
Or in a terminal inside this folder: python3 -m http.server 8000  then open http://localhost:8000
Photos: put images in /images and set them as background-image in css/photo.css.
